#+TITLE: Glucolog
#+DESCRIPTION: Дневник самоконтроля диабета для Android и Web
#+LANGUAGE: ru

Glucolog - приложение на Android для учета и контроля уровня глюкозы. У
приложения так же есть web-версия, но она устаревшая, и не поддерживает полезные
функции вроде синхронизации с xdrip+, web-версия больше не обновляется.

Актульную версию приложения можно найти в релизах, файл `app-release.apk`

* Возможности
- Сохранение данных о глюкозе и импорт/экспорт в csv/json.
- Синхронизация данных с XDrip+ для автоматического учета глюкозы
- Рассчет параметров как ФЧИ, УК, АИ, АГ на основе данных глюкозы, а так же
  данных о еде
- Калькулатор еды с подсчетом углеводов, а так же рассчетом инсулина на основе
  предыдущих показателей. В приложении встроено около 20000 продуктов из России,
  так же есть возможность добавлять свои.
- Дневник дня с возможностью записи текущего состояния, эмоций, заметок, выводов
  за день и т.д, полностью текстовый формат
